# Fit Prime Lab - Project Context

## Overview
Fit Prime Lab is a multilingual fitness platform providing tools, blog content, and guides for fitness enthusiasts and professionals.

## Vision
Transform from a tools-only website to a complete fitness platform featuring:
- **Tools** (calculators, converters, analyzers)
- **Blog** (educational content, guides, comparisons)
- **Guides** (future - comprehensive tutorials)
- **Apps** (future - mobile applications)
- **Community** (future - user interactions)

## Brand
- **Name:** Fit Prime Lab
- **Domain:** fitprimelab.com
- **Purpose:** Fitness knowledge and tools platform

## Supported Languages
- English (en)
- Spanish (es)
- Portuguese (pt)
- Japanese (ja)

## URL Structure
```
/[lang]/tools/[slug]
/[lang]/blog/[slug]
/[lang]/guides/[slug] (future)
```

## Tech Stack
- **Framework:** Astro
- **Hosting:** Cloudflare Pages
- **Content:** JSON (tools), MDX (blog)
- **Styling:** CSS/Tailwind (to be configured)
- **Type Safety:** TypeScript

## Core Principles
1. **SEO-First** - Programmatic SEO with proper schema markup
2. **Performance** - Static generation, fast loading
3. **Scalability** - Dynamic content system for growth
4. **i18n Support** - Full multilingual support
5. **User Experience** - Clean, intuitive interfaces

## Project Goals
- Rank for fitness-related keywords
- Build topical authority through content clusters
- Create sustainable, scalable content system
- Maintain high performance and SEO scores
