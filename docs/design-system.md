# Fit Prime Lab Design System

## General Style

- Clean and minimal design
- Inspired by modern fitness apps and Healthline articles
- Focus on readability and usability
- No visual clutter

---

## Colors

- Primary: black / dark gray
- Background: white
- Accent: subtle blue or green (fitness related)
- Avoid strong or aggressive colors

---

## Typography

- Large headings
- Clear hierarchy (H1, H2, H3)
- Easy-to-read font
- Plenty of spacing

---

## Layout

- Max width: 1100px
- Centered content
- Lots of whitespace
- Mobile-first design

---

## Tools UI (IMPORTANT)

Tools must be:

- extremely simple
- fast to use
- no distractions

Structure:

1. Title
2. Short description
3. Inputs
4. Result (highlighted)
5. Explanation
6. FAQ
7. Related content

---

## Inputs

- Large input fields
- Clear labels
- Placeholder examples
- Mobile-friendly

---

## Buttons

- Simple
- Rounded corners
- Clear CTA text (e.g. "Calculate")

---

## Results

- Highly visible
- Larger font
- Highlighted box
- Instant feedback (no reload)

---

## Blog Style

- Similar to Healthline
- Clean typography
- Large headings
- Easy reading
- Sections well separated

---

## UX Rules

- No friction
- No unnecessary clicks
- Instant results for tools
- Clear navigation

---

## Interaction

- No page reload for calculations
- Smooth transitions
- Lightweight JS only when needed

---

## SEO UI Rules

- Content must be visible without interaction
- Important text must not be hidden
- Use semantic HTML

---

## Accessibility

- Good contrast
- Labels for inputs
- Keyboard navigation
